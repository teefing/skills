# 技术文章发布前检查清单

在交付最终文章前，请逐项核对以下清单，确保所有要求均已满足。

## 结构与完整性

- [ ] **标题**：文章标题是否简洁、准确，并能概括核心内容？
- [ ] **序言**：是否包含引人入胜的开场、点明文章价值，并预告了核心概念？
- [ ] **章节完整**：是否包含了模板中所有的核心章节（如核心概念、实践应用、总结等）？没有遗漏？
- [ ] **分级标题**：文章是否使用了 `##` 和 `###` 等多级标题来组织内容，且层级逻辑清晰？
- [ ] **结语**：结尾部分是否对全文进行了总结，并提供了明确的号召性用语（Call to Action），如引导读者评论、关注或访问链接？

## 内容与风格

- [ ] **风格一致**：全文的写作风格是否与选定的风格（如“布道师风格”）保持一致？第一人称或第三人称视角是否统一？
- [ ] **术语准确**：文中的技术术语是否使用准确且一致？对于非通用缩写，是否在首次出现时提供了全称？
- [ ] **避免翻译腔**：通读全文，检查是否存在生硬、不自然的句子（翻译腔），并将其修改为流畅的中文表达。
- [ ] **避免过度术语化**：在保证专业性的前提下，是否尽可能使用了通俗易懂的语言来解释复杂概念？

## 富文本与排版

- [ ] **章节引导图**：每个核心章节（`##` 标题下）是否都配有一张高质量的引导图？
- [ ] **图文并茂**：文中的所有图片是否都有对应的文字说明？图片是否能有效辅助理解？
- [ ] **引用块使用**：是否正确使用了引用块（`>`）来突出显示引用的观点或名言？
- [ ] **Callout 使用**：是否在适当的位置（如强调核心观点、聚合资源链接）使用了 Callout 高亮块？
- [ ] **Grid 布局**：对于适合并排展示的内容，是否考虑并使用了 Grid 布局？
- [ ] **链接有效**：文中的所有超链接是否都可正常访问？
- [ ] **代码块**：文中的代码示例是否都使用了带语言标识的代码块进行格式化？

## 可读性

- [ ] **段落长度**：是否存在过长的段落？是否可以通过拆分或使用列表来优化？
- [ ] **标点规范**：全文是否统一使用了全角标点符号？
- [ ] **中英文间距**：中文字符与英文、数字之间是否都保留了一个半角空格？
