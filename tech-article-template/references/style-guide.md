# 技术文章风格指南

本指南旨在帮助你理解并运用高质量技术文章的写作风格、语言原则和富文本元素，以 `sample-article.lark.md` 为核心参考范例。

## 一、写作风格选择

技术文章的风格并非一成不变，不同的风格服务于不同的沟通目的。

### 风格一：布道师风格（Evangelist Style）- **默认选项**

这种风格旨在传递作者的见解、激发读者的思考和认同感，而不仅仅是陈述事实。

*   **核心特征**：
    *   **第一人称视角**：大量使用“笔者认为”、“我发现”等词语，拉近与读者的距离，分享个人思考过程。
    *   **观点鲜明**：敢于提出并论证自己的判断和预测，如“*笔者认为 Long-horizon Harness 是 2026 年值得重点关注的技术方向*”。
    *   **善用设问**：通过提问引导读者思考，如“*什么是 Harness？它和 Framework、Library 有什么区别？*”
    *   **富有感染力**：语言带有情感和号召力，结尾通常会引导读者进行下一步行动（如关注、加群、Star 项目）。

*   **何时使用**：当文章目的是分享个人经验、推广技术理念、解读行业趋势或进行产品布道时。

### 风格二：教科书风格（Textbook Style）

这种风格侧重于客观、准确地传递知识，如同教科书或官方文档。

*   **核心特征**：
    *   **第三人称视角**：使用客观、中立的语言，避免出现个人观点和情感色彩。
    *   **陈述事实**：专注于定义、原理、步骤的清晰阐述。
    *   **结构严谨**：逻辑层次分明，多使用定义、列表和表格。
    *   **语言精确**：术语使用标准，句子简洁明了。

*   **何时使用**：当文章目的是编写产品文档、技术手册、API 参考或纯粹的知识科普时。

## 二、叙事与语言原则

### 序言：引人入胜

*   **建立联系**：从一个具体的个人经历或观察入手（如“*最近笔者在 YouTube 上看了一期专题访谈...*”），快速拉近与读者的距离。
*   **点明价值**：清晰地告诉读者，阅读本文能获得什么（“*让笔者带着大家一起回顾一下这期干货满满的播客吧！*”）。
*   **预告核心概念**：在序言中就抛出文章将要探讨的核心概念（如 Long-horizon Agent, Harness），引发读者兴趣。

### 正文：结构与节奏

*   **分章节叙事**：将长篇文章分解为多个逻辑独立的章节，每个章节集中讨论一个核心主题。
*   **使用分级标题**：通过 `##` 和 `###` 构建清晰的内容层级，方便读者快速导航和理解文章结构。
*   **保持节奏感**：
    *   在段落之间留出空行，避免大段文字带来的压迫感。
    *   使用 `---` 分隔线在大的主题切换时，给读者一个“喘息”的空间。

### 引用与论证

*   **引用块（Blockquote）**：使用 `>` 突出显示引用的关键人物的言论或核心观点，以增强文章的权威性和说服力。
    *   **示例**：`> “让 LLM 在循环中运行，让它完全自主决定下一步做什么——这一直是 Agent 的核心理念。”`
*   **观点支撑**：在提出自己的观点后，紧接着通过引用或数据来支撑，形成“论点-论据”的完整逻辑链。

## 三、富文本元素用法

富文本不是装饰，而是提升信息传递效率的工具。

### 图片（Image）

*   **目的**：视觉化核心概念，或在章节开始时作为引导图（Banner Image）来设定基调。
*   **用法**：
    *   **章节引导**：在每个核心章节（`##` 标题）的开头放置一张与主题相关的图片，帮助读者快速抓住章节主旨。
    *   **图文结合**：图片下方应紧跟相关的解释性文字，不要让图片孤立存在。
    *   **格式**：使用 `![图片](img_url.png)`。

### 组合模块（Grid）

*   **目的**：并排比较或展示两种相关但不同的信息。
*   **用法**：
    *   当需要展示“代码与解释”、“优势与劣势”、“PC端与移动端视图”等场景时，使用 Grid 布局。
    *   **示例**：在范文中，通过 Grid 展示了 Github 仓库链接和二维码。

    ```
    <grid cols="2">
    <column width="47">
      **❤️ Github 仓库（求 Star）**
      https://github.com/bytedance/deer-flow
    </column>
    <column width="52">
      [此处放置二维码图片]
    </column>
    </grid>
    ```

### 高亮块（Callout）

*   **目的**：强调需要读者特别注意的信息，或聚合一组相关的资源链接。
*   **用法**：
    *   **强调金句或核心摘要**：用 Callout 框出每部分最核心的结论。
    *   **聚合资源**：将相关的文章、视频或项目链接统一放在一个 Callout 中，方便读者查阅。
    *   **示例**：范文末尾的“ByteTech x LLM 工程师养成系列”就是一个典型的资源聚合用法。
*   **格式**:
    ```
    <callout icon="unicorn_face" bgc="5" bc="5">
    **<font color="blue">ByteTech x LLM 工程师养成系列</font>**
    - **🎥《LLM 学习季》讲座回放：**[提示工程的艺术🎨工具与智能体](...)
    - ...
    </callout>
    ```
